# ПРОКЛИНАТОР

Комичное веб-приложение: сатирические «проклятия» на бытовые привычки. Шутка, не оккультизм. 18+.

Не является HR-процедурой.

## Деплой

Статический сайт без сборки — корень репозитория и есть публикуемая папка. Хост: **Vercel** (репозиторий приватный; публичный GitHub Pages не используется).
`vercel.json` добавляет заголовки, которые нельзя задать из документа (X-Frame-Options, Permissions-Policy, nosniff, HSTS, кэш шрифтов и иконок).
Адрес приложения не захардкожен: ссылки в подписях, постере и контактах берутся из `location`.

## Файлы

- `index.html` — разметка, стили, meta CSP (скрипты: только свой origin + jsDelivr с SRI; `worker-src 'self'` — только для `sw.js`). OG/Twitter-превью указывают на абсолютный адрес `https://proklinator-static.vercel.app/`.
- `app.js` — всё приложение (данные, движок ритуала, оболочка v19, вступление/документы/безопасность v20, тексты Фрейи и Тюра v20.1, аватар и ярлык «На экран „Домой“» v20.2 — строки Фрейи в `AVATAR_A2HS_COPY`, версия `avatar-a2hs-2026-09-11`; ритуальные эффекты v20.5 — рунные кольца, угли, пепел, дым; впечатанная строка «Шутка, не угроза» на картинках (v20.7.1 — своя полоса у нижнего края рамки, фиксированная высота над полом историй, `drawSafetyBand`); локальная геймификация v20.7 — тексты в `GAME_COPY`, версия `game-copy-2026-09-11`: «Серия» в профиле (мягкая серия по локальным дням, календарь на две недели, без упрёков), «Атлас печатей» во вкладке Категории (восемь категорий, пустой слот открывает ритуал с подсказкой), «Дело дня» над формой (подставляет только «Что случилось?»), шесть новых печатей, тихие бонусы кармы и порог «одно дело — не больше трёх ритуалов в сутки»; состояние — один проверяемый ключ `localStorage` `pk_game`, стирается вместе с остальным). Каталог в `DATA`: грехи 1–40 (быт + объект) и 41–60 (v20.6, PUNCH_PACK_v1 — офис, быт, отношения; только нейтральные приговоры `verdicts.N`, категория `byt`), к ним `sinKeywords` и `shareCaptions.bySinId`. Пополнение — только добавлением в конец, существующие `id` не меняются.
- `docs/content/` — исходники контентных пакетов от редакции: `DROPIN_PUNCH_PACK_v1.js` (грехи 41–60 с наброском слияния в `DATA`), `DROPIN_PUNCH_PACK_v1.md` (таблица пакета и чеклист), `PUNCH_PACK_v1.md` (все сцены с setup / три силы / lift), `SAFETY_PASS_v1.md` (проверка безопасности, GREEN), `DROPIN_SHARE_CAPTIONS_41_60_FIX.js` / `.md` (полные, не обрезанные `shareCaptions.bySinId[41–60]` — только подписи; в `DATA` пока лежит прежняя версия, приложение их не читает). В `app.js` не подключаются — справочные файлы; в приложение содержимое попадает через `DATA`.
- `tools/build_assets.py` — воспроизводимый конвейер бинарных ассетов (v20.5): алтарь 9:16 из `hero-altar.jpg`, производные PWA-иконки из мастера `icons/icon-512.png`, спрайты эффектов из Kenney (CC0), бумажное зерно из ambientCG Paper001 (CC0). Сторонние архивы скачиваются один раз в `.asset-sources/` (в git не попадает) и сверяются по SHA-256. `python3 tools/build_assets.py verify` проверяет размеры, пропорции и квадратность всего набора; нужен Pillow.
- `sw.js` — лёгкий service worker (v20.7.1): кэш оболочки (страница, `app.js`, манифест, иконки, шрифты, герой, образы, алтарь 9:16, спрайты эффектов и зерно заставки) для работы без сети. Регистрируется только в secure context; любая ошибка — тихая. При релизе поднимать `VERSION` и `APP_JS` вместе с `?v=` в `index.html`.
- `manifest.webmanifest`, `icons/` — PWA. `icon-512.png` — собственный мастер (корона в кольце, 512×512); `icon-192.png`, `apple-touch-icon.png` (180, сплющен на `#0B0908`) и `maskable-512.png` (непрозрачный, кольцо внутри безопасной зоны 80%) выводятся из него скриптом `tools/build_assets.py icons`.
- `assets/icons/` — SVG-иконки (стиль Lucide, `currentColor`) таббара, действий и вступления. Источник дизайна для инлайновых иконок в `app.js`/`index.html` (инлайн оставлен намеренно: наследует цвет активной вкладки, ноль запросов).
- `assets/icons/categories/` — значки восьми категорий (v20.3): файлы Lucide v0.469.0 как есть (ISC, заголовок лицензии внутри каждого файла): `users`, `briefcase`, `heart-crack`, `graduation-cap`, `home` (в Lucide — `house`), `smartphone`, `zap`, `globe`. Та же геометрия заинлайнена в `ICO` в `app.js` по `id` категории (`people`, `work`, `relations`, `study`, `home`, `tech`, `situations`, `world`); карточка PRO «Авторские» — свой значок.
- `ATTRIBUTIONS.md` — источники и лицензии: Lucide (ISC), Kenney Particle Pack / Smoke Particles (CC0), ambientCG Paper001 (CC0), Playfair Display (OFL), библиотеки с jsDelivr (MIT); аватары, алтарь, рисунки пустых состояний и PWA-иконки — собственные. Сторонних брендовых наборов нет.
- `assets/fx/` — спрайты ритуальных эффектов (v20.5): угли, искры, пепел, дым, молния, свечение печати — из Kenney Particle Pack и Smoke Particles (CC0), уменьшены и перекрашены в кровь/уголь скриптом `tools/build_assets.py fx`; `LICENSE-kenney.txt` лежит рядом. Загружаются лениво; пока не пришли — процедурное свечение, ритуал не ждёт сеть.
- `assets/empty/` — четыре собственных рисунка пустых состояний (v20.5): `quiet-candle` (история), `hollow-heart` (избранное), `unlit-altar` (ритуалы), `cold-ash` (по умолчанию). Та же разметка заинлайнена в `EMPTY_ART` в `app.js`.
- `assets/avatars/{hood,seal,raven,pack-3}.png` — аватары профиля (v20.2, UX_V202): `hood` — «Тёмный пользователь» по умолчанию, `seal` — восковая печать, `raven` — ворон, `pack-3` — триптих (лента из трёх медальонов; в круге виден средний). Выбор хранится в `localStorage` как `avatarId` = `hood|seal|raven|pack3`; если файл не загрузился — остаётся SVG-капюшон. Файл `pack-3.png` — JPEG-данные под расширением `.png` (браузеры распознают формат по содержимому).
- `assets/splash/altar-9x16.jpg` — алтарь за вступлением и заставкой: `<img alt="" aria-hidden>` на весь экран под сажевой вуалью 50%. С v20.5 — настоящий 9:16, 1080×1920: центральный кадр `hero-altar.jpg` (корона на оси), собирается `tools/build_assets.py altar`; прежний `altar-9x16.png` был JPEG 1280×720 под расширением `.png` и удалён. Если файл не загрузился — `hero-altar.jpg`.
- `assets/splash/paper-grain.jpg` — бумажное зерно заставки (v20.5): ambientCG Paper001 (CC0), приведённое к нейтральному серому; накладывается через `mix-blend-mode: overlay` с прозрачностью 6%.
- `fonts/` — Playfair Display (SIL OFL, см. `fonts/OFL.txt`), самохостинг.
- `hero-altar.jpg` — герой формы и заставки, он же картинка превью ссылки.
